# Upgrade to 18.0.6.0

This release upgrades the existing `car_wash_dashboard` module in place.

- Do **not** uninstall the previous module.
- Do **not** delete existing POS/MRP automations.
- Do **not** recreate manufacturing orders.
- Push this addon version, update the Apps list if needed, then upgrade `car_wash_dashboard`.
- After upgrade, configure the 10 wash stations under **Car Wash → Station Configuration**.
- The dashboard is read-only for operational state; all start/finish actions remain in Shop Floor.

# Optional native integration examples

These files are **not loaded by Odoo** and are intentionally excluded from `web.assets_backend`.

Odoo 18 runs this dashboard with Python + OWL/JavaScript + QWeb/XML + SCSS/CSS. C++ and VB.NET cannot run inside the Odoo browser client. The examples below are kept only as future companion code for an external kiosk, gate controller, LED display, or local integration service. They contain no credentials and make no database changes.

- `cpp/car_wash_visual_math.cpp`: C++17 example for station utilization/progress calculations.
- `vbnet/CarWashKioskPreview.vb`: VB.NET console example for a future external display model.
